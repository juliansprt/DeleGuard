# 16 - Product / Architecture Questions to Resolve

1. Hosted PDP only vs customer-side PDP from beta?
2. OPA/Rego internally vs Cedar vs native evaluator?
3. Pricing: authorization checks, active protected agents, or enterprise platform fee?
4. Is approval part of core price or premium?
5. How much resource data can customers safely send to the SaaS?
6. Should high-risk customers send only hashes/attributes and keep raw data local?
7. How should actor identity be cryptographically bound for custom agents?
8. Which first vertical gives clearest ROI: coding/DevOps, finance/payments, SaaS admin operations, or invoicing?
9. Does the market value proof-of-execution enough to differentiate from generic authorization?
10. What is the first supported enterprise enforcement boundary: SDK, Envoy/ext_authz, API gateway plugin, or sidecar?
