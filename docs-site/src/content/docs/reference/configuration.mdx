## API y worker

| Clave | Local | Producción |
| --- | --- | --- |
| `ConnectionStrings__Postgres` | `Host=localhost;Port=5432;Database=deleguard;Username=deleguard;Password=deleguard` | Cadena del proveedor, TLS, usuario de menor privilegio |
| `Redis__ConnectionString` | `localhost:6379` | Opcional; si falta, la API sigue siendo correcta |
| `Permits__SigningKey` | `deleguard-dev-permit-hmac-key-change-in-prod-32` | Secreto ≥ 32 chars, rotación controlada |
| `Permits__Issuer` | `deleguard` | Identificador estable de tu despliegue |
| `DemoAuth__ApiKeyPepper` | `deleguard-dev-pepper` | Pepper de KMS; rotar implica re-hashear keys |
| `DemoAuth__ConsoleToken` | `dgc_demo_console_local_dev_only` | Sustituir por SSO |
| `DemoAuth__DemoOrganizationId` | `org_demo` | No usar este id en prod |
| `DELEGUARD_ENTRYPOINT` | — | `api` o `worker` en la misma imagen |
| `Docs__PublicUrl` | `http://localhost:4321` | Origen público de la documentación de este entorno |
| `ASPNETCORE_ENVIRONMENT` | `Development` | `Production` |

## Clientes

| Variable | Default del ejemplo |
