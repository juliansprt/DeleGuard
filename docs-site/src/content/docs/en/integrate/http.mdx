Use **Agents, Actions, and Policies directly with `POST /v1/authorize`**, without configuring AI Gateway, providers, models, budgets, or Guard MCP. Your application enforces the decision before executing and can report the result with `POST /v1/executions`. AI Gateway is optional for model calls; Guard MCP is optional for MCP tools.

import { Aside } from '@astrojs/starlight/components';

Any language that speaks HTTP is enough. There is no published SDK yet; use these endpoints.

## Headers

| Header | Required | Notes |
| --- | --- | --- |
| `Authorization: Bearer dgk_…` | Yes (agent) | Never the `dgc_` console token. |
| `Idempotency-Key` | Yes on authorize | 8–128 characters. Same key = same decision. |
| `Content-Type: application/json` | Yes | Snake_case body. |
| `X-Deleguard-Agent-Id` | No | Convenience. |
| `traceparent` | No | W3C / OpenTelemetry. |

## `POST /v1/authorize`

```http
POST /v1/authorize HTTP/1.1
Host: 127.0.0.1:5080
Authorization: Bearer dgk_demo_invoice_agent_local_dev_only
Idempotency-Key: 9f1c0a2b7e334c1a
Content-Type: application/json
```

```json
{
  "agent": { "id": "invoice-agent", "environment": "production" },
  "actor": { "id": "usr_481", "type": "human" },
  "action": "invoice.cancel",
  "resource": {
    "type": "invoice",
    "id": "FAC-DRAFT",
    "attributes": {
      "amount": 5000000,
      "currency": "COP",
      "status": "draft",
      "reportedToTaxAuthority": false
    }
  },
  "context": { "reason": "demo" }
}
```

### 200 responses

```json
{ "decision": "ALLOW", "decision_id": "dec_…", "permit": "…" }
```

```json
{ "decision": "DENY", "decision_id": "dec_…", "reason": "…" }
```

```json
{ "decision": "REQUIRE_APPROVAL", "decision_id": "dec_…", "approval_id": "apr_…" }
```

<Aside type="caution">
`DENY` is 200. 401 = `invalid_agent_credential` / `unauthorized`. 400 = `invalid_request` (e.g. missing `Idempotency-Key`). 503 = `authorization_unavailable` → **do not execute**.
</Aside>

## After ALLOW

```http
POST /v1/executions
Authorization: Bearer dgk_…
Content-Type: application/json
```

```json
{
  "decision_id": "dec_…",
  "status": "SUCCESS",
  "provider_reference": "erp-cancel-8821"
}
```

Response **202**. `status`: `SUCCESS` | `FAILED` | `PARTIAL` | `UNKNOWN`.

## Read a decision

```http
GET /v1/decisions/{decision_id}
Authorization: Bearer dgk_…
```

Useful after `REQUIRE_APPROVAL` once a human has approved: GET reflects current state.

## Approve (human / console, not the agent)

```http
POST /v1/approvals/{approval_id}/approve
Authorization: Bearer dgc_…
```

```json
{ "note": "ok for this invoice", "expires_at": "2026-09-13T18:00:00Z" }
```

Deny: `POST /v1/approvals/{approval_id}/deny`.
