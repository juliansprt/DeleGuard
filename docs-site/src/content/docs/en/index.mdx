## Three decisions, one contract

| Decision | What the agent does |
| --- | --- |
| `ALLOW` | Execute the action. Keep `decision_id` and the `permit`. |
| `DENY` | Do not execute. HTTP **200** with `decision=DENY` — not a network error. |
| `REQUIRE_APPROVAL` | Wait. A human approves in the console, then a permit appears. |

The `invoice.cancel` demo covers all three: cheap draft → ALLOW; high-value issued → REQUIRE_APPROVAL; tax-reported → DENY.
