## Tres decisiones, un contrato

| Decisión | Qué hace el agente |
| --- | --- |
| `ALLOW` | Ejecuta la acción. Conserva `decision_id` y el `permit`. |
| `DENY` | No ejecuta. HTTP **200** con `decision=DENY` — no es un error de red. |
| `REQUIRE_APPROVAL` | Espera. Un humano aprueba en la consola y entonces aparece un permit. |

La demo `invoice.cancel` cubre las tres: borrador barato → ALLOW; emitida de alto valor → REQUIRE_APPROVAL; reportada a Hacienda → DENY.
